# DeepSeek Harness 桌面壳

[English](README.md) | 中文

Electron 应用在本机回环端口启动当前源码目录的 `dsh web` 服务，并在一个启用沙箱的窗口中加载它。在已准备好的源码目录运行 `pnpm --filter @deepseek-ai/dsh-desktop start`。桌面壳不会打包或替换源码目录。

更新页通过 Host 插件检查 `deepseek-ai/deepseek-harness` 的发布。较新版本有与当前平台及架构匹配的官方安装包时，点击「更新 DeepSeek Harness」会将其写入用户的「下载」目录，并在完成后通过操作系统打开。进度反映已写入字节数；无法得知总大小时显示不确定进度。失败、取消、传输不完整或摘要不匹配时会删除未完成文件，已有下载不会被覆盖。安装仍需按照操作系统提示完成；「打开安装包」可再次打开已下载的文件。没有匹配的官方安装包时，页面仅显示官方发布链接，不显示更新控件。桌面壳不会替换当前源码目录。
