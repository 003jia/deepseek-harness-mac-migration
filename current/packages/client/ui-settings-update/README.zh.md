# @deepseek-ai/dsh-client-ui-settings-update

[English](README.md) | 中文

Web 设置中的官方更新界面。它注册 `update` `settings.section` 和一个位于 `sidebar.footer.action` 的图标操作；该图标会直接在「更新」页打开 Settings。进入页面和点击「重新检查」都会调用生成的 `updateCheck` Remote。请求尚未完成时显示不带虚构百分比的进度条。卡片会标明官方来源、对比当前版本与最新版本、显示官方发布时间，并且只链接到官方 DeepSeek Harness 发布页。较新版本有匹配的官方桌面安装包时，点击「更新 DeepSeek Harness」会将其下载到「下载」文件夹，显示真实字节进度并支持取消，然后通过操作系统打开下载完成的安装包。普通 Web 客户端仍使用官方下载安装链接。发布没有匹配安装包时，卡片会明确说明。安装仍需按照操作系统提示完成；两种客户端都不会替换源码目录。

## 模型体验

无，因为这个仅 UI 的包不注册提示词、工具、消息或提供方请求。

#### KV Cache 影响

无；本包从不组装模型输入。

## 已知限制与暂缓事项

- **不后台轮询** —— 侧边栏操作只会打开设置页；只有该页面挂载或用户重新检查时才会读取发布信息。
